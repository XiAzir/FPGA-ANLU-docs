# 硬件操作

读取条件：给出或执行供电、接线、烧录过程中的实物操作、运行与断电步骤时。

- 调整 JTAG 排线、跳线、GPIO 接线或拆装核心板/模块时先断电；烧录期间不主动断电、复位或拔线，等待软件明确完成。
- 板卡保留已经稳定的“插座 + USB 电源适配器 + USB-A 转 USB-C 线”接法，USB 供电使用正常 5V 输出；其他电源的电压、极性、电平及多路供电须先核对。不能向板卡 USB 口强制输入 9V/12V。
- AL-LINK 接电脑，板卡由独立电源供电；不要把下载器当作整板电源。
- 当前现成流水灯/HDMI 内部测试图运行结束后，可以确认没有烧录任务再直接断板卡电源；复位不等于断电，`PROGRAM_SRAM` 配置掉电丢失。
- TF 写入或 Flash 擦写期间不得随意断电、拔卡；未明确支持热插拔的 TF 流程按断电插拔处理。换 HDMI 线建议先断板卡电源再操作。
- GPIO 外设先核对方向、共地和电平，不把 5V 电源/信号直接接到未确认能承受的 FPGA 引脚，也不将两路推挽输出直接相连。
- 板卡放在干燥的绝缘桌面或支架上，避免底部金属短接、触碰引脚及线材牵拉。出现焦味、冒烟或明显短路迹象时立即断电。
- 用户更换上述供电接法后，HDMI 黑屏、白色噪点和黑横线消失；电源来源与线材同时变化，只能定位原供电链路，不能单独认定某根线或电脑 USB 口是根因。

需分析具体供电图或历史症状时，再读取 [HDMI 与供电专题](../开发记录/专题记录/HDMI基础显示与供电排查/README.md)。
