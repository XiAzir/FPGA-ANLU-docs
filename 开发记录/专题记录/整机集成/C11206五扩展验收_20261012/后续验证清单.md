# 后续验证清单（计划，尚未执行）

基准：[C11206五扩展总表](README.md)。本清单不覆盖已经收到的普通功能正常反馈，用于补当前缺项以及检验后续优化版。波形分辨率优化尚未开发，动态双线按用户选择暂留。

## 验证顺序

| 顺序 / 关联TC | 操作与观察 | 留档与通过边界 |
| --- | --- | --- |
| 1 波形显示优化（可选质量分支）；TC19/TC24 | 在新隔离工程提高横向/纵向显示精度与线条可读性，保持真实PCM输入、冻结/恢复和两音源；用模型先对已知音形、窗口提交、换源/冻结验证，再正式构建并相关板测 | 新版源、bit、模型、资源、setup/hold与原版对照绑定。具体目标/资源预算开发前定稿；不把清晰度改善自动称作动态双线根因修复。可跳过，以C11206直接进入下项补证 |
| 2 连续五扩展补证；TC16–TC21/TC24 | 在拟最终候选拍一段连续操作：版本D页→四尺寸图/手动擦除→AUTO→BRI/CON及默认恢复→音乐/波形HOLD恢复→内部音阶/HOLD恢复。字幕滚动和运行时间变化保持可见，保留现场声音 | 建议约1–2分钟，足够辨认操作即可；建议时长不是赛题门槛。记录实际bit路径/hash、build ID、素材、设备与日期。参数改变前后画面和数值同镜可见。旧版媒体仅作历史对照；无需现在重复录制 |
| 3 交互稳定；TC02/TC26 | 在功能通过候选运行并穿插切图/AUTO、两音源、参数/默认、HOLD恢复；适量测试加载或转场中触发，核对忙时策略 | 原计划建议2小时；真实开始/结束时间、异常时间、操作、供电和设备另记。观察死锁、图像破坏、音频杂音/中断和恢复；没有执行就不填通过 |
| 4 音画并发长稳；TC14/TC27 | 音乐循环+AUTO+字幕+波形持续运行，保持接线；观察文件循环、切图及错误状态 | 原计划建议8小时；独立计时和事件记录，用户到场确认声音/画面。LED/数码管只作辅助，不能单凭常亮判连续播放。任何父版本30分钟记录不继承 |
| 5 SRAM重复启动诊断（可选，不计TC28） | Flash前如需排查启动一致性：确认完全断电→上电→重新PROGRAM_SRAM下载同一候选→检查挂载、图片、两音源、按键；记录实际等待时间、次数、失败及重试 | SRAM阶段必须重新下载，仅是启动/卡初始化诊断，不是掉电自启验证，不作为当前验收前置。TC28留到最终Flash后执行 |
| 6 支持与异常素材；TC03–TC14/TC25 | 优先用合成镜像完成范围明确的模型；板测用备份后的专用素材/卡，补最大尺寸、更多正负高度/padding、坏头/截断/超限/无卡/空目录/读超时。按实现核对拒绝、旧图保留、错误诊断和复位恢复 | 原卡/原音乐保留；不为整理修改实验室TF。模型和实物结果分列；未设计的热插拔/格式不列支持。发生故障保存首个错误、bit、素材hash与时间，不补写未知恢复行为 |
| 7 文件/卡与碎片；TC06/TC08/TC12/TC14 | 在相同bit下比较受支持素材的不同位置、连续/碎片簇链及另一张受支持FAT32卡；观察top-down反向访问、音频服务与图像进展 | 记录卡布局/簇链、素材SHA、实际加载和长稳情况。文件层模型覆盖不等于真实卡已验；不承诺固定加载等待时长 |
| 8 范围冻结、最终审计/复现、固化；T36/TC28/TC30/TC31 | 确定保留功能与已知问题；对最终候选核对资源、有效setup/hold路径、时钟/例外/未覆盖项和关键告警，并在干净目录或第二电脑按依赖清单复现；封存RC，再编制Flash步骤、固化及不经PC下载的冷启动；报告/视频/源码/位流统一版本 | TC28前提是最终Flash且无PC下载，原计划建议10次，记录首图/首声、实际次数和连续影像。当前C11206仅成功开发基线，型号/固化流程及提交规则届时核准；尚未写Flash、复现最终RC或提交。本次资料整理不计最终封版 |

2小时、8小时、10次来自原开发计划建议；不是已完成结果，也不作为未经核准的官方要求。若显示优化暂不采用，可直接以C11206带已知项推进保留范围验证；不因可选质量改进卡住交付。

## 记录模板

| 字段 | 实际填写内容 |
| --- | --- |
| 版本 | 工程/bit绝对路径、SHA256、板上D页build ID、SRAM/Flash方式 |
| 环境 | 板卡、供电、HDMI线、显示设备、识别模式、音量、操作者；显示器读数和代码名义值分开 |
| 素材 | 文件名、格式/尺寸、主机SHA、卡上SHA（实际读取才填）、盘符/卡布局 |
| 时间 | 开始/结束北京时间、真实持续时间；不将OSD RUN单张读数当长稳起止 |
| 操作 | TC编号、实际按键/切源/模式/循环/冷启动次数；未数的次数留空 |
| 结果 | 用户观察/仪器/照片/视频/计数/模型分列；错误时间、现象、是否可复现及回退对照 |
| 附件 | 原照片/连续原视频路径与SHA；对应构建、素材与测试日志 |

异常时先保存证据，在相同供电/HDMI/素材条件下回载C11206；若再退C11205，须恢复原640×480 BMP。无需重复索要旧诊断数码管视频，也不直接操作当前远程实验室硬件。
