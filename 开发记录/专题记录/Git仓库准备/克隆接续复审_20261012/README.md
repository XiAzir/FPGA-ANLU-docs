通用 `main` 的有效 TD/模型/Python 入口从自身位置解析工程及资料仓，工具通过环境变量或 PATH 找到；当前活跃资料链接采用相对路径。`checkpoints` 中脚本、日志和 JSON 保存历史原貌，读取原机器的记录路径时使用路径适配器。

改造过的有效脚本与旧阶段上下文不同，生成产物缺省不提供原 live 数据库；重新构建从 synthesis 开始，并用入口生成新的阶段凭据。新构建不能继承旧版用户实板反馈。
