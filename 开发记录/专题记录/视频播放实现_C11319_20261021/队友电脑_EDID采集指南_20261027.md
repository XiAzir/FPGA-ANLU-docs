# 队友电脑采集指南：显示器 EDID

适用：Windows 10 / 11。采集脚本使用系统自带的 Windows PowerShell 5.1 和 WMI，输出原始 EDID、校验信息及 ZIP。

## 本次要确认什么

现有实测：

| 测试版本 | 输出内容 | 像素 / 串行时钟 | 用户反馈 |
| --- | --- | --- | --- |
| C33 / C36 | 1920×1080、15Hz 固定彩条 | 33 / 165MHz | 无信号；D3、D1、D0亮，D2闪烁 |
| C35 | 640×480、60Hz 固定彩条 | 同为33 / 165MHz | 完整稳定彩条；D2闪烁更快 |

这次采集显示器向电脑提供的 EDID，用来查看其声明的显示模式和时序范围。后续结合 HDMI 核的输出核验，继续定位 1080p15 无信号的原因。

## 操作步骤

1. 将 FPGA 测试时使用的**同一台显示器**，用**同一根 HDMI 线**连接队友电脑。打开显示器，选择相应 HDMI 输入。
2. 在显示器上看到正常的电脑桌面后，记录 Windows“设置 → 系统 → 屏幕 → 高级显示”中这台显示器的名称。多屏电脑请记清目标显示器对应的名称；脚本会采集所有活动显示器。
3. 把本压缩包**完整解压到一个普通文件夹**，例如桌面的 `ANLU_EDID`。从解压目录双击 **Run_EDID.cmd**。
4. 等窗口显示 `Active monitors captured:` 和结果 ZIP 路径，再按任意键关闭。通常数秒完成。
5. 同目录会出现 `EDID_result_日期_时间.zip` 和同名文件夹。**把这个新生成的结果 ZIP 发回**，同时写一句“板子用的是 ×× 显示器”。

电脑若只有目标显示器一块活动屏幕，说明“采集时只有这一块屏幕”即可。

## 发回什么

- `EDID_result_日期_时间.zip`。
- 目标显示器名称，或“采集时只有这一块屏幕”。
- 若方便，附一张电脑桌面已在目标显示器上正常显示的照片，便于对应现场。

结果 ZIP 内包含：

| 文件 | 内容 |
| --- | --- |
| `capture.json` | Windows监视器身份、活动状态、块数、校验值和SHA256 |
| `Summary.txt` | 显示器名称及采集摘要 |
| `monitor01_edid.bin` | 第一台活动显示器的完整原始EDID，含扩展块 |
| `monitor01_block00.bin` 等 | 各128字节块，便于独立复核 |
| `monitor01_edid.hex.txt` | 同一EDID的十六进制文本 |

有多台活动显示器时，会继续生成 `monitor02_*` 等文件。

## 遇到问题

- **窗口出现红色报错**：保留整个窗口截图，并把已经生成的 `EDID_result_*` 文件夹压缩后发回；截图需包含错误开头和结尾。
- **报“Access denied / 拒绝访问”**：右键 `Run_EDID.cmd`，选“以管理员身份运行”，再采集一次。若仍报错，把完整截图发回。
- **显示 `Active monitors captured: 0`**：确认目标显示器已显示电脑桌面；在 Windows 显示设置里启用它，再运行脚本。
- **仅有电脑主屏幕，目标显示器未亮**：先在 Windows 显示设置里选“扩展”或“复制”，等目标屏幕显示桌面后再采集。
- **电脑为 macOS / Linux**：把系统类型发回，再提供相应系统的采集步骤。

## 执行内容

脚本通过 WMI 的 `WmiMonitorID` 和 `WmiMonitorDescriptorMethods.WmiGetMonitorRawEEdidV1Block` 读取活动显示器，写入本目录的新结果文件夹，再压缩。启动器的 `ExecutionPolicy Bypass` 作用于本次 PowerShell 进程。运行所需文件均已放在包内。

采集期间使用电脑给显示器输出画面。FPGA后续测试继续使用既有TF素材，C32保留作播放器正常回退，C35保留作本次彩条对照。
