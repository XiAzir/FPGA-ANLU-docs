# C11307 频谱柱：ROM读控制/ODDR准备沿及板端诊断（实板待验证）

C11306默认音乐PCM输入正常却无音画，tone有图/闪点/杂音、频谱空。此版四ROM读控制对齐TD推断配置，只把ODDR两位准备沿从serial上升沿改下降沿（pixel marker/wrapper保持C11206），global init仍off。增加被动频谱B/C诊断；TF/音频/PLL/复位/引脚/SDC保持，唯一实物原因未确认。

从实际播放PCM计算1024点Hann窗FFT，显示24频段幅值柱。深色底/青色柱、快速抬升/缓慢回落、顶部峰值保持；频谱从左低频到右高频。柱高采用对数映射，非功率谱。显示扩大为128行面板；图片主体、现有字幕和参数功能继续集成。

解压到连接板卡电脑的纯英文目录。BitWriter Add spectrum_observed.bit → PROGRAM_SRAM /5MHz → Run，确认下载成功；D页须显示 DFC11307。维持现有TF卡、供电、HDMI和音量。

B页（B开头，第二位仍为PCM前缀flags）后三字节为FFT完成帧数，切音源清零，应持续增长。C页后三字节为8bit状态和16bit上一FFT帧最大幅值；状态从高到低依次PCM见到/FFT帧完成/非零频段/Hann非零/twiddle非零/显示提交/可见高度非零/冻结。非静音正常运行通常高字节FE，HOLD时FF；不能只看一个瞬间或静音段。若异常，请录完整一轮数码管（约22秒），包含D/B/C页，不要只拍屏幕。

1. 默认WAV音乐：画面/字幕应清楚、声音连续；观察鼓点和旋律对应频谱变化及峰值回落。
2. 长按KEY1约2秒：切内部音阶，柱峰应随音调改变位置；再次长按回音乐。切源时频谱清空后重建。
3. 双键短按并松开测试HOLD/恢复：HOLD冻结柱和峰值，声音继续播放；恢复后显示最新音频。
4. 顺手核对图片切换/轮播、亮度对比度、OSD和多尺寸图片。异常用包内bmp_scale.bit(C11206)回退。

本地独立算法/像素/控制模型（PRIVATE_ROM_BEHAVIORAL_SIM）和最终原约束时序通过；官方受保护BRAM原语不能由Icarus仿真，初始化另外以正式gate INIT解码核对；setup +0.365ns、hold +0.024ns，TNS0。实板声音、显示、观感与长期稳定性仍待确认。
