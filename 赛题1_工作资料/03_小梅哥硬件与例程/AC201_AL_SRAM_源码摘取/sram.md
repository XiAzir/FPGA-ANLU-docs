# IS61WV25616EDBLL-10TLI 手册中文总结

本文基于 ISSI 数据手册 `IS61WV25616EDBLL / IS64WV25616EDBLL`（Rev. A2，2020-07-14）整理，重点聚焦你当前使用的器件 `IS61WV25616EDBLL-10TLI`。

## 1. 这颗芯片是什么

`IS61WV25616EDBLL-10TLI` 是 ISSI 的一颗异步 SRAM，主要特征如下：

- 存储组织：`262,144 x 16 bit`，也就是 `256K x 16`，用户可见容量为 `4 Mbit`
- 类型：`Asynchronous CMOS Static RAM`
- 封装：`44-pin TSOP (Type II)`，无铅
- 速度等级：`10 ns`
- 工作电压：`2.4 V ~ 3.6 V`
- 温度等级：`Industrial`，`-40°C ~ +85°C`
- 接口特点：无时钟、无刷新、三态数据口、支持高/低字节独立访问
- 附加特性：内部带 ECC，可对每个字节进行单 bit 错误检测与纠正

一句话理解：这是一颗 `16 bit 宽、10 ns、工业级、带透明 ECC 的异步 SRAM`。

## 3. 存储组织与 ECC

### 3.1 存储组织

- 地址线：`A0 ~ A17`，共 18 根
- 数据线：`I/O0 ~ I/O15`，共 16 根
- 地址空间：`2^18 = 262,144` 个地址
- 每个地址宽度：`16 bit`

因此这颗 SRAM 对外表现为：

- `262,144` 个字
- 每字 `16 bit`
- 总容量 `4,194,304 bit`

### 3.2 字节划分

- `LB#` 控制低字节 `I/O0 ~ I/O7`
- `UB#` 控制高字节 `I/O8 ~ I/O15`

所以它既可以整字读写，也可以只访问低 8 位或高 8 位。

### 3.3 ECC 机制

手册明确说明：

- 每个字节各自拥有独立 ECC
- 每字节可检测并纠正 `1 bit` 错误
- 相比奇偶校验，ECC 不仅能检测错误，还能纠正错误
- 对系统来说是“透明”的，属于向下兼容，可作为无 ECC 标准异步 SRAM 的直接替代

从功能框图可以看出：

- 低 8 位数据阵列旁边有一组 `256K x 4` 的 ECC 阵列
- 高 8 位数据阵列旁边也有一组 `256K x 4` 的 ECC 阵列

这说明 ECC 是芯片内部实现的，外部接口仍然保持标准 `16 bit SRAM` 的用法。

## 4. 主要特性

手册首页给出的关键特性如下：

- 高速访问时间：`8 ns / 10 ns`
- 低活动功耗：`85 mW typ`
- 低待机功耗：`7 mW typ`（CMOS standby）
- 单电源供电
- `10 ns` 版本支持 `VDD = 2.4V ~ 3.6V`
- 全静态工作：不需要时钟，不需要刷新
- 三态输出
- 支持高/低字节控制
- 支持工业级和车规级温度范围
- 提供无铅封装
- 支持 ECC

对你的器件来说，最重要的是：

- 它是异步 SRAM，不需要时钟
- 电源只要满足 `2.4V ~ 3.6V`
- 时序控制主要靠 `CE# / OE# / WE# / LB# / UB#`

## 6. 工作模式与真值表

### 6.1 基本规则

- `CE# = 1`：芯片未选中，输出高阻，进入待机相关电流状态
- `WE# = 1`：配合 `OE#` 可进行读操作
- `WE# = 0`：进入写操作路径
- `LB# / UB#`：决定低字节和高字节是否参与读写

### 6.2 手册真值表整理

| 模式 | `WE#` | `CE#` | `OE#` | `LB#` | `UB#` | `I/O0-I/O7` | `I/O8-I/O15` | 说明 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 未选中 | X | H | X | X | X | High-Z | High-Z | 待机 |
| 输出禁止 | H | L | H | X | X | High-Z | High-Z | 芯片已选中但不输出 |
| 输出禁止 | X | L | X | H | H | High-Z | High-Z | 两个字节都未使能 |
| 读低字节 | H | L | L | L | H | Dout | High-Z | 只读低 8 位 |
| 读高字节 | H | L | L | H | L | High-Z | Dout | 只读高 8 位 |
| 读整字 | H | L | L | L | L | Dout | Dout | 读 16 位 |
| 写低字节 | L | L | X | L | H | Din | High-Z | 只写低 8 位 |
| 写高字节 | L | L | X | H | L | High-Z | Din | 只写高 8 位 |
| 写整字 | L | L | X | L | L | Din | Din | 写 16 位 |

### 6.3 实际使用时的理解

- 读操作的典型条件是：`CE#=0`、`WE#=1`、`OE#=0`
- 写操作的典型条件是：`CE#=0`、`WE#=0`，并且 `LB#` 或 `UB#` 至少有一个为低
- 如果 `LB#` 和 `UB#` 都拉高，那么数据口不会参与有效读写

## 8. 功耗参数

下面这组数据要注意条件：均为 `Over Operating Range`，其中动态电流是在 `VDD = Max`、`IOUT = 0`、`f = fMAX` 条件下测得。

### 8.1 你的器件（-10、Industrial）的电流指标

| 参数 | 测试条件 | 典型值 | 最大值 |
| --- | --- | --- | --- |
| `ICC` 动态工作电流 | `VDD = Max, IOUT = 0, f = fMAX` | `21 mA` | `35 mA` |
| `ICC1` 静态工作电流 | `VDD = Max, IOUT = 0, f = 0` | - | `25 mA` |
| `ISB1` TTL 待机电流 | `CE# >= VIH, VIN = VIH or VIL, f = 0` | - | `15 mA` |
| `ISB2` CMOS 待机电流 | `CE# >= VDD - 0.2V`，输入靠近电源或地，`f = 0` | `1.5 mA` | `6 mA` |

### 8.2 该表的工程含义

- 如果 `CE#` 拉高，芯片可以进入待机
- 若输入也满足 CMOS 电平条件，待机电流应参考 `ISB2`
- 如果输入停在 TTL 电平而不是靠近轨到轨电平，则待机电流更接近 `ISB1`

这也是为什么实际板子上，如果 `CE#` 没拉高或者输入悬空，待机电流会明显偏大。

## 9. 读时序参数（-10 档）

以下时序数值是对你的 `-10` 速度等级最直接有用的部分。

### 9.1 读周期切换特性

| 符号 | 含义 | `-10` 数值 |
| --- | --- | --- |
| `tRC` | 读周期时间 | `10 ns` |
| `tAA` | 地址访问时间 | `10 ns` |
| `tOHA` | 输出保持时间 | `2.0 ns` |
| `tACE` | `CE#` 到数据有效 | `10 ns` |
| `tDOE` | `OE#` 到数据有效 | `4.5 ns` |
| `tHZOE` | `OE#` 到高阻 | `4 ns` |
| `tLZOE` | `OE#` 到低阻 | `0 ns` |
| `tHZCE` | `CE#` 到高阻 | `4 ns` |
| `tLZCE` | `CE#` 到低阻 | `3 ns` |
| `tBA` | `LB# / UB#` 到数据有效 | `6.5 ns` |
| `tHZB` | `LB# / UB#` 到高阻 | `3 ns` |
| `tLZB` | `LB# / UB#` 到低阻 | `0 ns` |
| `tPU` | 上电进入活动时间 | `0 ns` |
| `tPD` | 进入低功耗时间 | `10 ns` |

### 9.2 读操作怎么理解

- 地址稳定后，最迟 `10 ns` 可以在数据口读到有效数据
- 如果地址不变，只是切换 `OE#`，最迟 `4.5 ns` 数据有效
- 如果地址不变，只切换 `LB# / UB#`，最迟 `6.5 ns` 对应字节有效
- 取消片选或取消输出后，数据口会在几纳秒内回到高阻

对板级测试来说，`tAA = 10 ns` 和 `tDOE = 4.5 ns` 是最常盯的两个读参数。

## 10. 写时序参数（-10 档）

### 10.1 写周期切换特性

| 符号 | 含义 | `-10` 数值 |
| --- | --- | --- |
| `tWC` | 写周期时间 | `10 ns` |
| `tSCE` | `CE#` 到写结束 | `8 ns` |
| `tAW` | 地址建立到写结束 | `8 ns` |
| `tHA` | 地址保持（相对写结束） | `0 ns` |
| `tSA` | 地址建立时间 | `0 ns` |
| `tPWB` | `LB# / UB#` 有效到写结束 | `8 ns` |
| `tPWE1` | `WE#` 脉宽 | `8 ns` |
| `tPWE2` | `WE#` 脉宽（`OE# = LOW`） | `10 ns` |
| `tSD` | 数据建立到写结束 | `6 ns` |
| `tHD` | 数据保持（相对写结束） | `0 ns` |
| `tHZWE` | `WE# LOW` 到输出高阻 | `5 ns` |
| `tLZWE` | `WE# HIGH` 到输出低阻 | `2 ns` |

### 10.2 写操作的关键点

手册明确说明，内部写入由以下低电平重叠区间定义：

- `CE# = LOW`
- `WE# = LOW`
- `LB#` 和 `UB#` 中至少有一个为 `LOW`

只要以上条件成立，就会触发写入。  
而写结束可以由这些信号中任意一个失效来终止，因此：

- `tSD` 和 `tHD`
- `tSA` 和 `tHA`

都要相对于“终止写周期”的那个边沿来检查。

另外有两个很实用的结论：

- 若写周期中 `OE#` 保持低电平，则 `WE#` 脉宽要求更严，必须满足 `tPWE2 = 10 ns`
- 手册允许 `WE#` 在多个地址周期内持续为低，通过切换 `LB# / UB#` 来实现 back-to-back write

## 11. 数据保持特性

当系统掉压但仍希望 SRAM 保持数据时，手册给出如下参数：

| 参数 | 含义 | 数值 |
| --- | --- | --- |
| `VDR` | 数据保持电压 | `2.0V ~ 3.6V` |
| `IDR` | 数据保持电流（Industrial） | 最大 `6 mA` |
| `tSDR` | 进入数据保持前建立时间 | `0 ns` |
| `tRDR` | 恢复时间 | `tRC` |

进入数据保持模式的关键条件是：

- `VDD = 2.0V`
- `CE# >= VDD - 0.2V`

也就是在降压前要先把 `CE#` 拉高到接近 `VDD` 的电平，让芯片进入数据保持模式。

## 14. 对板卡设计和调试最有价值的几点

如果把整份手册压缩成最实用的几条，建议记住下面这些：

1. 这是 `18 位地址 + 16 位数据` 的标准异步 SRAM，没有时钟脚。
2. 正常工作范围对你的料号是 `2.4V ~ 3.6V`、`-40°C ~ +85°C`。
3. 读操作常用组合是 `CE#=0, WE#=1, OE#=0`。
4. 写操作必须满足 `CE#=0, WE#=0`，并且 `LB# / UB#` 至少有一个有效。
5. `LB#` 控制低字节，`UB#` 控制高字节，两个都拉高会让数据口无效。
6. `CE#` 拉高后芯片进入待机，若输入满足 CMOS 电平，待机电流按 `ISB2` 看。
7. `-10` 档的核心时序是：`tAA=10ns`、`tDOE=4.5ns`、`tWC=10ns`、`tPWE1=8ns`、`tSD=6ns`。
8. 写周期里若 `OE#` 保持低电平，`WE#` 脉宽要求要放宽到 `10ns`。
9. 器件内部带 ECC，可对每字节纠正 1 bit 错误，但对外仍按普通异步 SRAM 使用。
10. TSOP 封装上 `28` 脚是 `NC`，不要误接。
