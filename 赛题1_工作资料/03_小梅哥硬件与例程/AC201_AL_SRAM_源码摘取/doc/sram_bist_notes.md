# SRAM BIST 说明

## 顶层说明

- 顶层模块：`sram_bist_top`
- 时钟输入：`clk50_i`
- 独立 LED：`led0_o`
- SRAM 位宽：`16 bit`
- SRAM 地址宽度：`18 bit`

## BIST 阶段

| 阶段编号 | 含义 |
| --- | --- |
| `0x00` | 全空间写 `0x0000` |
| `0x01` | 全空间读回并比较 `0x0000` |
| `0x02` | 全空间写 `0xFFFF` |
| `0x03` | 全空间读回并比较 `0xFFFF` |
| `0x04` | 全空间写 `0xAAAA` |
| `0x05` | 全空间读回并比较 `0xAAAA` |
| `0x06` | 全空间写 `0x5555` |
| `0x07` | 全空间读回并比较 `0x5555` |
| `0x08` | 全空间写 `addr[15:0]` |
| `0x09` | 全空间读回并比较 `addr[15:0]` |
| `0x0A` | 全空间写 `~addr[15:0]` |
| `0x0B` | 全空间读回并比较 `~addr[15:0]` |
| `0x0C` | 全空间写 `0x55AA` |
| `0x0D` | 全空间读回并比较 `0x55AA` |
| `0x0E` | 仅写低字节，写入 `0xCC` |
| `0x0F` | 读回并比较 `0x55CC` |
| `0x10` | 仅写高字节，写入 `0x77` |
| `0x11` | 读回并比较 `0x77CC` |

## LED 规则

- 运行中：慢闪
- 测试通过：常亮
- 测试失败：快闪

## 约束说明

- `A18` 没有放进顶层和约束，因为当前实装器件是 `IS61WV25616EDBLL-10TLI`，该脚为 `NC`
- `LED0` 采用独立指示灯 `B3_M5`
- `LED1~LED5` 与 SRAM 地址线复用，本工程故意不使用
